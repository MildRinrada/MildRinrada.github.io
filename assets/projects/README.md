# Project images

One folder per place, named after its `id` in `data/town.js`:

```
assets/projects/
  kawaiibake/
    cover.webp      ← shown in the detail panel
  bookdose/
    cover.webp
```

- **cover.webp**: 1600 × 1000 (16:10), ideally under ~200 KB. Export as WebP from Photoshop, or convert at squoosh.app.
- Until a file exists, the panel shows a "Screenshot coming soon" frame, so nothing breaks.
- Work projects: only use screenshots your company has approved. Blur or replace real client data.
